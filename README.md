Diese interaktive Webseite soll eine erste Orientierung bei der Umstellung der Prüfungsordnugen zum Wintersemester 26/27 an der Uni Oldenburg liefern. Nicht mehr und nicht weniger. 
Insbesondere kann dieses Tool keine rechtliche Beratung oder Studienberatung ersetzen.
Eine Weiterentwicklung kann gern in der Community erfolgen.
Das Tool ist bisher komplett mit Claude Opus 4.8 entwickelt worden auf der Basis der entsprechenden Beschlüsse in der Fakultät II der UOL, sowie durch entsprechende klärende Eingaben.
